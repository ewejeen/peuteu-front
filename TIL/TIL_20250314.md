# On 20250314 I learned...
## 1. debounce: 텍스트 입력과 동시에 중복 확인을 하고 싶을 때 API 통신이 계속 되는 것 방지
- keyup 이벤트 등으로 input에 중복 확인 API를 호출하는 함수를 넣을 경우, 자판을 한 글자 누를 때마다 API가 호출됨
- 결국 중복 확인이 필요한 데이터는 입력이 모두 끝난 후의 데이터인데, 중복 확인 버튼 클릭 없이 키보드 입력으로만 확인하려다 보니 과하게 API가 호출되고, 서버 부하가 증가됨
- 이를 방지하기 위해 `watch + debounce` 방법을 사용

### watch + debounce 사용하기
- 사용자가 입력을 마칠 때까지 기다렸다가 API를 호출
- `lodash` 라이브러리를 사용하는 방법이 있고, `lodash` 없이 `setTimeout`을 사용할 수도 있음
  - `lodash` 사용 예제: https://velog.io/@nemo/lodash-debounce
- 우선 라이브러리 도입 없이 `setTimeout` 방식으로 구현함
- `vuetify`의 `rules` 검사 기능으로 실시간 validation을 진행하고 있으므로, `watch`는 사용하지 않았음
### 코드
```html
<div class="text-subtitle-1 text-medium-emphasis">아이디(이메일)</div>
      <v-text-field
        variant="outlined"
        v-model="userId"
        :rules="[
          rules.email.duplicated,
        ]"
      ></v-text-field>
```
```javascript
<script>
export default {
  data() {
    return {
      ...
      userId: null,
      userIdDup: null,
      rules: {
        email: {
          ...
          duplicated: (value) => {
            if(!value) return true;
      
            if (this.debounceTimerId) {
              clearTimeout(this.debounceTimerId);
            }
      
            return new Promise((resolve) => {
              this.debounceTimerId = setTimeout(async () => {
                const isDuplicated = await this.checkDuplicatedEmail();
                resolve(isDuplicated ? "이미 등록된 이메일입니다." : true);
              }, 300);
            });
          }
        },
      };
      ...
    }
  },
  methods: {
    async checkDuplicatedEmail() {
      const payload = { email: this.userId };
    
      try {
      const result = await checkEmail(payload);
      if (result && result.data.result === "success") {
        this.userIdDup = result.data.data.duplicated;
      } else {
        console.log("실패");
      }
      } catch (error) {
        console.error(error);
      }
      
      return this.userIdDup;
    },
    ...
  }
};
</script>
```

- Vuetify의 `rules`는 값 또는 `Promise`를 반환하는 비동기 함수를 기대하므로 `setTimeout` 내부에서 `Promise`를 반환하도록 함
  - `new Promise((resolve) => { ... })`
- `setTimeout`을 이용해 500ms 후에 실행되도록 하고, `checkDuplicatedNickname(value)`를 호출한 뒤, 결과에 따라 `resolve()`를 호출하도록 함
  - 사용자가 입력을 멈춘 후 500ms 뒤에 비동기 검사가 실행되고, 결과가 `rules`로 반환됨.
- `checkDuplicatedNickname` 함수 또한 `async` 처리
